ARCADE V0.3

Sector 01: First Contact

The visual system is now built as deliberate low-resolution pixel art: layered starfield, pixel settlement silhouette, asteroids, scout/interceptor/mine enemy classes, enemy fire, power-up sprites, explosions and the Moerverse Warden boss.

The playable ships use your original uploaded pixel spacecraft artwork. The source sprites face north, so the game rotates them 90° clockwise at render time to face the combat direction without modifying your source files.
